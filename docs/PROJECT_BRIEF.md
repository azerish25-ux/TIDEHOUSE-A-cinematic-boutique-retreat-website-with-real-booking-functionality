# Authoritative project brief

Build TIDEHOUSE: an agency-quality, cinematic direct-booking website for one fictional coastal retreat with five individually designed cabins. Use Next.js, TypeScript, PostgreSQL, editable content and a payment-provider sandbox. Keep scope to five cabins, two add-ons and one complete reservation workflow; do not build a marketplace or a hotel-management platform.

The defining interaction links an illustrated property map to cabin views, galleries, floor plans, amenities and actual dated availability. Guests can compare two cabins, choose a stay, add breakfast or a second experience and review the complete price before paying in test mode.

Required working behavior: availability search; date selection; guest-capacity limits; seasonal pricing; booking confirmation; cancellation; a protected owner interface for blocking dates and changing rates; and editable guest/editorial content. Two visitors must not both confirm overlapping stays in the same cabin. A failed payment must never leave a falsely confirmed reservation.

Required content: local guide, access information, arrival instructions, cabin-specific FAQs, inclusions and clear booking terms. The fictional nature of the property must not be disguised as real operating evidence.

Art direction: cinematic landscape and interior imagery, generous space, sea-glass and sand tones, elegant editorial type, natural material references, a hand-illustrated property plan and restrained motion. No generic accommodation template, invented reviews or decorative controls that do nothing.

User requested Figma, image generation and GitHub delivery. The repository records the Figma file and actual asset provenance separately; the current photographic assets are references, not generated output. Source, operational limits and verification evidence must remain honest.
